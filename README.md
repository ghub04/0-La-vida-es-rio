# Proyecto Final — *La vida es río*

Este repositorio contiene el código fuente y los recursos del proyecto final del máster. El proyecto explora la relación entre la emoción, la memoria y la experiencia digital, a través de una propuesta web interactiva que combina arte, narrativa visual y tecnología.

## Objetivo del proyecto

El objetivo principal es crear una experiencia web inmersiva y poética que permita al usuario navegar por diferentes “islas emocionales”, cada una vinculada a fragmentos literarios, imágenes y sonidos, transmitiendo una sensación fluida y orgánica inspirada en la metáfora del río.

## Estructura del proyecto

El proyecto está organizado en módulos para facilitar la escalabilidad y el mantenimiento del código:

```
/assets        → imágenes y archivos multimedia
/fonts         → fuentes del proyecto
/css           → hojas de estilo principales y parciales  
/js            → scripts organizados por funcionalidad  
/index.html    → punto de entrada principal  
/README.md     → documentación del proyecto  
```

## Control de versiones

Este repositorio es **privado** y se utiliza como entorno de trabajo y seguimiento del desarrollo.
Cada commit documenta una fase o ajuste del proyecto, incluyendo optimización de estilos, pruebas y mejoras, también mejoras según el feedback recibido en clase.
